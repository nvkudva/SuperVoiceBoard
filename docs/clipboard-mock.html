What the colour says

Violet — permanent. Pinned card, filled pin, violet hairline. Nothing else in the panel is violet.
Spectrum meter — time left in the retention window; a pinned clip has none, which is the contrast that explains pinning.
Cyan / coral / green — clip type only: link, image, phone. Type glyphs never use violet.
Coral — destructive: clear-all key, swipe-to-delete track.

Toolbar strip

Same 10 px rounded square and #141834 functional fill as the main toolbar — but grouped into pills (cursor · edit) with clear-all pushed to the leading edge and close to the trailing edge, so the six keys read as three intents instead of one undifferentiated row.
Paste is shown in its active violet state — the only lit key, so the strip has one focal point.
Component behaviour
Long-press keeps working and stays the power path; the visible pin is the discoverable one. Pinned clips lose the meter entirely and lose the swipe-to-delete track, which matches the existing manager rules.
